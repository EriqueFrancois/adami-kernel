## Purpose

Frontend React source code for the `adami-kernel` Web Console.

## Key files

- `main.tsx`: application bootstrap (React root mount).
- `App.tsx`: main application shell.
- `Dashboard.tsx`: dashboard UI.
- `Market.tsx`: market UI.
- `MemoryPanel.tsx`: memory/workflow UI panel.
- `SkillsPanel.tsx`: skills list/panel UI.
- `SkillCard.tsx`: skill card component.
- `App.css`, `index.css`: styles.

## Key subdirectories

- `assets/`: images/icons used by the UI.
