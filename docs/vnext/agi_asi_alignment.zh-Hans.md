## AGI/ASI 对齐（工程化标准）— AdamI 北极星

本文把“成熟 AGI / ASI”的口号翻译成 **可工程化、可验收** 的标准，用于长期路线规划与取舍。
它与 vNext（季度）路线图配套：季度路线图负责“近端可落地”，本标准负责“长期方向不跑偏”。

### 定义（务实版）

- **成熟 AGI（实用）**：能在广泛新任务分布上可靠完成任务，具备学习复利，且在约束下安全运行。
- **ASI**：在大多数认知任务上超越人类，并快速自我改进。

在开源内核的语境里，“更接近”意味着：**能力 + 可靠性 + 可度量 + 安全** 同步前进。

## 1) 成熟度标尺（成熟系统必须具备什么）

> 详细的 5 级工程验收标准见：`docs/vnext/agi_acceptance_levels.zh-Hans.md`。\n

### A) 有边界的自治（Autonomy with bounded risk）

- **目标分解**：把意图转成可检查的计划/工作流与中间状态。
- **长程执行**：部分失败可恢复，并能从持久化 checkpoint 续跑。
- **预算约束**：时间/成本/工具预算显式化并强制执行。
- **可控性**：人类随时可暂停/取消/覆盖。

### B) 可复利的学习（Learning that compounds）

- **评测体系**：行为回归（golden traces）+ 回放 + 评分。
- **经验→策略闭环**：把教训沉淀为规则/策略/模板/测试，而不是只写日志。
- **A/B 可比对**：任何改动都能用同一套回放“前后对照”。

### C) 世界模型与记忆治理（World model & memory governance）

- **写入纪律**：来源、去重键、密钥策略，以及“为何写入”的理由。
- **检索带引用**：凡使用记忆的回答都带 citations（路径/笔记 id），便于审计。
- **污染控制**：摄入抗 prompt 注入；明确标记“不可信内容”。

### D) 工具与 Agent 互操作（Interop）

- **工具边界**：标准化工具协议 + 策略 + 可观测（MCP 风格）。
- **Agent 边界**：标准化委派生命周期（A2A 风格），与传输无关。

### E) 安全是系统属性（Safety as a system property）

- **脱敏** 与 **沙箱** 默认开启，而不是事后补丁。
- **高风险操作需显式同意（HITL）**，并留下可追溯审计记录。
- **攻击面可观测**：工具调用可追踪、可归因。

## 2) AdamI 当前的优势（已具备的成熟原语）

- 事件驱动内核 + 有界并发 + 工作流状态持久化。
- 每 chat 持久化队列 + hard-timeout 防占锁卡死。
- 安全基建：总线脱敏、技能审计/洗髓、可选沙箱。
- 可观测底座：OTel 采样 + 导出脱敏策略。
- Replay 骨架（校验 + inject 扩展点），可升级为完整评测体系。

---

## 3) 最大阻塞点（短板）

按复利价值排序：

1) **first-class 评测体系**（golden traces + replay + scoring）——没有它，“自进化”无法被信任。  
2) **统一生命周期合约**（跨渠道、跨边界一致）。  
3) **预算 + 取消传播**（planner → tools → workflows 全链路）。  
4) **互操作边界**（MCP tools + A2A agents）并带策略/观测。  
5) **记忆治理 + citations**（提升能力但不牺牲可审计）。  

---

## 4) 与 vNext（季度）的映射关系

从“北极星”到“季度交付”的评判方式：\n
- 北极星（本文）定义 **方向**：自治/复利学习/记忆治理/互操作/安全。\n
- 5 级验收标准（`agi_acceptance_levels`）定义 **门禁**：每个 Level 的可测指标与测试套件。\n
- vNext（季度）路线图定义 **近期交付**：每个里程碑必须明确映射到某些 Level 的“前置门槛”。\n

- 里程碑 A：推进 **有边界自治**（超时、生命周期 UX、控制面）。  
- 里程碑 B：建立 **复利学习**（评测 + 回放 + 评分卡）。  
- 里程碑 C：确立 **互操作边界**（生态级能力扩展的前提）。
