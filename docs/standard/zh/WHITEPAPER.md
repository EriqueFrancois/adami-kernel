# AdamI — 商业白皮书（价值主张）

**读者**：投资人、业务决策层、并购（M&A）。**不能**替代法律与财务尽调。

本文阐述架构选择的**商业价值**，不涉及实现细节；工程表述请以 [ARCHITECTURE.md](ARCHITECTURE.md)、[SECURITY.md](SECURITY.md) 及源码为准。

---

## 1. 市场痛点（当今 Agent 系统）

| 痛点 | 买方感知症状 | AdamI 对应方向 |
|------|--------------|----------------|
| **记忆脆弱** | 一重启就失忆、「Agent 忘了」 | `LayeredMemory` SQLite、SecondBrain 笔记、追加式经验池 |
| **执行失控** | 异步任务风暴、供应商限流雪崩 | `system.events` 消费侧 **信号量上限**、DLQ 纪律 |
| **链条不可审计** | 无法还原谁批准了什么 | `WorkflowEngine` 持久化 DAG；`hitl.events` 人机门闩 |
| **提示注入与密钥外泄** | 日志/工单截图带密钥 | 总线中间件 **脱敏**、类保险库签名密钥、入站代码 AST 清洗 |
| **集成成本高** | 每个渠道重复写路由 | 统一 `AdamiEvent` + `EventBus` + 多平台 Nerve |

## 2. 差异化（护城河表述）

1. **内核化而非 Demo**：显式生命周期、类型化事件、编排层 —— 在叠加贵司策略后，可面向受控工作流场景。
2. **进化式技能闭环**：外源 / LLM 产出技能经 **静态审计** 与 **洗髓** 后方可进入运行时（见 [SECURITY.md](SECURITY.md)）。
3. **可运营产出物**：Report Studio（`/report run …`）将研究型简报落入 SecondBrain 路径 —— 可作为 **B2B 工作流 SKU**（研究台、合规包、分析师桌面）。

---

## 3. 商业场景（说明性）

> **重要**：开源仓库**不包含**券商实盘凭证或交易密钥。任何 **收益率、延迟、夏普比率** 等数字必须来自**贵方**受控评测；不得将占位营销句视为经审计业绩。

- **研究与简报台**：按日/周/月生成可配置板块报告，写入 SecondBrain。
- **需审计的内部 Copilot**：DAG 状态 + HITL，适用于采购/法审等（策略层由客户承担）。
- **托管 Agent 服务**：Telegram / Discord / CLI 多感官汇入同一决策核，降低多表面工程重复。

---

## 4. 收入与打包（建议视角）

- **开源核心 + 商业服务**：上线辅导、托管总线、企业 SSO、VPC 内模型。
- **Acqui-hire 价值**：团队展示 **系统工程**（异步内核、沙箱、i18n 门禁）而非仅提示词工程。

---

## 5. 风险（坦诚）

- **依赖面**：大模型供应商、Docker 沙箱可用性、可选桥（如 DeerFlow）增加运维面。
- **安全是流程**：开源有利于尽调，但**生产**仍需渗透测试、密钥轮换与最小权限。
